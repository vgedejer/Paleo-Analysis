# Archive

This folder contains legacy files from earlier stages of this project. These resources were originally used for prototyping data collection, transformation, and exploratory analysis before the current structured pipeline and application architecture were adopted.

## Structure

- **data-reserve/**  
  Contains CSV files generated from early versions of the `data_collection.ipynb` notebook. These files were used to manually inspect and verify data fetched from the PaleoDB and other sources.

- **notebooks/**  
  A collection of Jupyter notebooks used for exploratory data analysis, initial visualizations, and early feature planning. Some notebooks also include preliminary taxonomic filtering and time range plotting.

## Purpose

These files are preserved for reference and historical context. While not actively used in the current application, they may still be valuable for:
- Reviewing the evolution of the data model
- Reusing or adapting early charting logic
- Cross-validating current outputs with previous methods

## Note

No scripts in this folder are actively maintained or expected to run without modification. For current functionality, refer to the `scripts/` and `web/` directories along with the main application codebase.
