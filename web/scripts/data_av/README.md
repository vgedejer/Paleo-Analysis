# 📊 Paleobiology Data Analysis & Visualization

This folder contains Jupyter notebooks focused on exploratory data analysis (EDA), data visualization, and hypothesis testing using the `paleo.db` SQLite database. These notebooks are designed to surface paleobiological insights through spatial, temporal, and taxonomic patterns in the fossil record.

## 🧬 Data Sources

All notebooks operate on the structured SQLite database `paleo.db`, which was created using data pulled from:
- [PaleoDB API](https://paleobiodb.org/)
- Wikipedia (for readable metadata enrichment)

Tables used:
- `genera`
- `species`
- `occurrences`
